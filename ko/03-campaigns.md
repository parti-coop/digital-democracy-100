# 📣 시민 캠페인
{: .no_toc }

시민이 사회 문제에 함께 목소리를 내고 행동하는 다양한 방식. 빠띠 캠페인즈는 서명·촉구를 넘어 한국 시민 캠페인 문화에 맞춘 다양한 형식을 자체 개발해 왔고, 시민이 직접 캠페이너로 성장할 수 있는 교육·컨설팅 프로그램을 함께 운영합니다.

## 플랫폼 기능
{: .text-delta }

캠페인즈가 시민 누구나 쉽게 운영할 수 있도록 제공하는 캠페인 형식.

### 1. 서명 캠페인

✅ 구현 완료
{: .label .label-green }

시민의 서명을 모아 정책 결정자나 기관에 전달하는 기본 캠페인 형식. 로그인 없이도 참여 가능합니다.

[설악산 케이블카 반대 서명 캠페인](https://campaigns.do/campaigns?type=signing){: .btn .btn-outline .fs-3 }

### 2. 촉구 캠페인

✅ 구현 완료
{: .label .label-green }

특정 기업·정부·기관의 행동 변화를 촉구하는 캠페인 형식. 시민의 목소리가 구체적인 요구로 묶입니다.

[캠페인즈 촉구 캠페인 모음](https://campaigns.do/campaigns){: .btn .btn-outline .fs-3 }

### 3. 목소리 모으기

✅ 구현 완료
{: .label .label-green }

서명만이 아니라 시민이 직접 자신의 의견·경험·이야기를 글로 남길 수 있는 캠페인 형식. 정책 결정 과정에 시민의 구체적인 목소리가 직접 전달됩니다.

[캠페인즈 목소리 모으기](https://campaigns.do/campaigns){: .btn .btn-outline .fs-3 }

### 4. 인증샷 모으기

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

시민이 캠페인 참여 인증샷을 올리고, 그 사진들이 모여 집단적 행동의 증거가 되는 빠띠 고유의 캠페인 형식. 한국 시민 캠페인 문화의 인증샷 전통을 디지털 광장으로 옮긴 사례.

[참여연대 천만 걸음 챌린지 인증샷](https://campaigns.do/campaigns/258){: .btn .btn-outline .fs-3 }

### 5. 지도에 모으기

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

시민이 자신의 지역에서 관찰한 문제를 지도 위에 표시해 모으는 캠페인 형식. 지역별·공간별로 분산된 시민 데이터가 시각적으로 한자리에 모입니다.

### 6. 추모 캠페인

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

사회적 비극의 희생자를 함께 추모하고 기억하기 위한 캠페인 형식. 시민의 추모 메시지·꽃·기록이 한 광장에 모입니다. 한국 사회의 집단 애도 문화를 디지털에서 구현한 사례.

### 7. 캠페인 소식 알리기

✅ 구현 완료
{: .label .label-green }

캠페인 참여자에게 진행 상황과 결과를 자동으로 이메일 발송하는 기능. 한 번 참여한 시민이 캠페인의 전 과정을 함께 지켜볼 수 있습니다.

### 8. 관심사 기반 캠페인 매칭

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

시민이 구독하는 이슈, 캠페이너의 활동, 그리고 유사 캠페인을 자동으로 매칭해 발송하는 알고리즘. 시민이 자신의 가치관에 맞는 캠페인을 자연스럽게 만나고, 한 캠페인의 참여가 다음 캠페인의 참여로 이어집니다.

## 이벤트·방법론
{: .text-delta }

캠페인을 함께 만들고 발전시키는 빠띠의 교육·컨설팅 프로그램.

### 9. 캠설팅 (캠페인 컨설팅)

✅ 구현 완료
{: .label .label-green }

캠페인을 시작하려는 시민·단체에게 빠띠가 제공하는 컨설팅 프로그램. 디지털 캠페인 기획부터 운영, 보도자료 작성, 후원 연계까지의 전 과정을 함께 만들어 갑니다.

[캠설팅 신청 안내](https://campaigns.do/stories/752){: .btn .btn-outline .fs-3 }

### 10. 캠페이너 페스타

✅ 구현 완료
{: .label .label-green }

캠페인·팩트체크·뉴스·토론·워크숍이 한자리에서 펼쳐지는 빠띠의 정기 축제. 시민 누구나 캠페이너가 될 수 있는 기회를 만듭니다.

[2024 캠페이너 페스타](https://campaigns.do/stories/752){: .btn .btn-outline .fs-3 }

### 11. 캠페이너 인생게임

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

캠페인 운영 과정을 게임으로 체험할 수 있도록 빠띠가 자체 개발한 워크숍 방법론. 가상의 캠페인 과정을 따라가며 시민이 캠페이너의 역할을 직접 경험합니다.

## 향후 과제
{: .text-delta }

캠페인의 효과를 더 명확하게 드러내고, 시민이 더 깊이 참여할 수 있게 하는 방향.

### 12. 캠페인 임팩트 측정 자동화

⬜ 향후 과제
{: .label }

캠페인이 만든 정책 변화·미디어 노출·사회 영향을 자동으로 추적하고 시각화하는 기능. 캠페인이 끝난 후에도 그 임팩트가 지속적으로 보이도록.
