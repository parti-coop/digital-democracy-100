# 🏛️ 거버넌스와 시민의회
{: .no_toc }

시민의 제안이 숙의를 거쳐 실제 정책이 되는 전 과정. 빠띠는 단순한 제안 수렴 창구를 넘어, 시민 제안 → 숙의·공론 → 시민의회·투표 → 정책화의 다층적 시민협력플랫폼 모델을 만들어왔습니다. 이 모델은 데모스X 가이드로 공개되어 누구나 자기 광장을 만들 수 있고, AI를 활용한 대규모 시민 의견 분석으로 시민이 직접 의제를 발굴하는 단계까지 도달했습니다.

## 플랫폼 기능
{: .text-delta }

데모스X가 제공하는 시민협력플랫폼의 핵심 기능.

### 1. 시민 제안 시스템

✅ 구현 완료
{: .label .label-green }

시민 누구나 자신의 일상과 지역에서 발견한 문제를 정책 제안으로 제출할 수 있는 시스템. 익명·실명 선택 가능, 첨부 자료 업로드, 비슷한 제안 자동 연결 등을 지원합니다.

[데모스X 시민협력플랫폼](https://demosx.org){: .btn .btn-outline .fs-3 }

### 2. 제안 숙의·공론 프로세스

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

제안된 안건이 단순 다수결로 결정되지 않고 시민 간 토론·전문가 의견·기관 답변을 거쳐 숙의되는 구조화된 프로세스. 빠띠가 10여 년의 운영 경험으로 발전시킨 "주제조정·선정 → 사전검토 → 사전토론 → 전문가포럼 → 열린소통포럼 → 사후토론 → 국민참여단 평가 → 숙성포럼 → 정책화"의 다층적 흐름이 데모스X의 핵심입니다.

### 3. AI 기반 대규모 의견 분석

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

수천에서 수만 건의 시민 의견을 AI로 자동 분류·요약·분야별 패턴 추출하는 기능. 단순 다수결을 넘어 시민이 직접 의제를 발굴하는 새로운 단계의 거버넌스를 가능하게 합니다. 시민이 제안한 의견을 AI가 분석한 결과는 다시 전문가 검토, 시민 패널 토의, 투표를 거쳐 의제로 확정되고, 이후 본격적인 사회적 대화로 이어집니다.

### 4. 시민의회·시민 패널 운영

✅ 구현 완료
{: .label .label-green }

추첨 또는 모집으로 구성된 시민 대표가 깊이 있게 정책을 숙의하는 도구. 무작위 추첨 추출, 패널 워크숍 진행, 합의문 작성, 결과 발표까지를 지원합니다.

### 5. 시민 투표·정책 결정

✅ 구현 완료
{: .label .label-green }

숙의된 안건에 대해 시민이 직접 투표로 결정하는 시스템. 빠띠 타운홀의 대규모 투표 기능과 결합되어 주민참여예산, 시민총회, 정책 결정 투표에 사용됩니다.

[빠띠 타운홀](https://townhall.kr){: .btn .btn-outline .fs-3 }

### 6. 정책화 추적

✅ 구현 완료
{: .label .label-green }

시민 제안이 정책으로 이어지는 전 과정을 시민이 추적할 수 있는 기능. 검토·심사·결정·실행 단계가 시각적으로 표시되고, 단계별 진행 상황과 담당 기관의 답변이 공개됩니다.

### 7. 운영 가이드·체크리스트 시스템

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

시민협력플랫폼을 도입하려는 기관이 단계별로 따라할 수 있는 운영 가이드와 체크리스트. 200여 회의 공론장 운영 경험을 정리한 빠띠 고유의 자산. 단계별 목표 설정부터 운영 원칙, 실무 체크리스트까지 포함됩니다.

[데모스X 가이드](https://demosx.org){: .btn .btn-outline .fs-3 }

### 8. 열린 모델과 운영 가이드

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

데모스X 모델은 2017년 서울시와의 협업에서 오픈소스와 오픈 가이드로 처음 공개되었습니다. 공개만으로는 유지 비용을 함께 나눌 방법이 없었고, 도입을 원하는 작은 조직에는 직접 구축할 기술 인력이 없었기에 이후 서비스로 전환했습니다. 지금 열려 있는 것은 200여 회의 공론장 운영 경험을 담은 데모스X 가이드이고, 그 가이드대로 플랫폼을 짓는 솔루션은 믹스온입니다. 어떤 기관이든 처음부터 만들 필요 없이 검증된 모델을 가져다 자기 맥락에 맞춰 발전시킬 수 있습니다. 시민의 광장은 시민의 것이라는 빠띠의 신념이 모델과 노하우의 공개로 이어진 형태.

### 9. 시민 정책 실험실

✅ 구현 완료
{: .label .label-green }

시민이 제안했거나 지역·기관에서 화두가 된 의제를, 정책이 되기 전에 작은 규모로 실행해 실효성과 시민의 수용성을 확인하는 실험 프로그램. 빠띠가 '실험장'이라는 이름으로 운영해온 방식을 잇고 확장했습니다. 의제 선정 → 실험 설계 → 실험 운영(통상 3~6개월) → 결과 분석 → 공론화·정책 연계의 5단계로 진행되며, "임산부석에 인형을 놓아두면 임산부들만 앉을까?"처럼 결과가 눈에 보이도록 실험 질문을 구체적으로 설계하는 것이 핵심입니다. 채택과 미채택의 이분법에 갇히던 시민 제안이 사장되지 않고 실험과 공론을 거쳐 성장하는 중간 단계. 데모스X를 통해 2025년까지 누적 107팀의 시민 실험을 지원했으며, 실험 결과는 은하투표·별별대화·코러스 등 후속 숙의의 출발점이 됩니다. (6번 시민 기술 카테고리의 '시민 기술 실험실'과 한 짝을 이룹니다.)

[시민 정책 실험실 툴킷](https://campaigns.do/toolkits/testing-ground){: .btn .btn-outline .fs-3 }

## 거버넌스 사례
{: .text-delta }

데모스X 기반으로 운영되는 한국의 시민협력플랫폼들.

### 10. 민주주의서울 / 상상대로 서울

✅ 구현 완료
{: .label .label-green }

서울시의 시민협력플랫폼. 빠띠가 2017~2019년 총괄 기획·운영했고, 천만 명 이상의 서울 시민이 직접 정책을 제안하고 결정할 수 있는 모델로 만들었습니다. 2019년 iF 디자인어워드(서비스디자인 부문) 수상. 2022년 12월부터 "상상대로 서울"로 명칭이 변경되어 운영 중입니다.

[상상대로 서울](https://idea.seoul.go.kr){: .btn .btn-outline .fs-3 }

### 11. 광화문1번가 / 정책소통포럼

✅ 구현 완료
{: .label .label-green }

행정안전부가 운영하는 범정부 시민참여 플랫폼. 빠띠가 2021년부터 열린소통포럼 운영을 맡아왔고, 현재 정책소통포럼으로 발전하여 빠르게 변화하는 사회문제에 대응해 국민과 정부가 함께 토론하고 정책을 만드는 범정부 공론장 역할을 하고 있습니다.

### 12. 모두의 국민통합

✅ 구현 완료
{: .label .label-green }

대통령 직속 국민통합위원회의 시민참여 플랫폼. "현장형 국민대화"라는 이름으로 4,215건 이상의 시민 제안을 6개 분야(정치·이념, 양극화, 지역, 세대, 젠더, 사회적 약자)로 모으고, AI 분석을 통해 의제를 발굴합니다. 발굴된 의제는 전문가 검토, 시민 패널 토의, 투표를 거쳐 확정된 후 본격적인 사회적 대화로 이어지는 빠띠의 다층적 시민협력플랫폼 모델의 가장 발전된 사례.

[모두의 국민통합](https://cohesion.or.kr){: .btn .btn-outline .fs-3 }

### 13. 천만의 연결

✅ 구현 완료
{: .label .label-green }

윤석열 퇴진 이후 시민들이 만들어갈 세상을 함께 꿈꾸는 온라인 공론장. 약 세 달 동안 788건의 시민 의견을 모아 AI 기반 분석 도구로 9개 분야로 분류·정리했습니다. 분석 결과는 사회대개혁특위 11개 소위원회의 정책 개발로 이어지고, 각 정당과 정치권의 공약·정책에 반영됩니다. 빠띠의 AI 기반 대규모 의견 분석이 시민사회 운동의 의제 발굴에 적용된 사례.

[천만의 연결 결과 리포트](https://talk.bisang1203.net/pages/10million-connections-report2){: .btn .btn-outline .fs-3 }

### 14. 기후 시민의회

✅ 구현 완료
{: .label .label-green }

탄소중립법 개정과 기후위기 대응을 위한 시민의회 공론화 프로젝트. 시민이 직접 의제를 제안하고 토론하며, 입법과 정책 결정에 시민의 목소리가 반영되도록 하는 사회적 대화 플랫폼.

[기후 시민의회·공론화](https://talks.campaigns.do/goals/climate-public-deliberation){: .btn .btn-outline .fs-3 }

### 15. AI 민주주의 시민대화

✅ 구현 완료
{: .label .label-green }

AI 시대의 민주주의를 시민이 직접 묻고 함께 이야기하는 공론장. "AI 시대에 모두의 민주주의를 다시 묻다" 연속 특강과 시민 질문 수집을 통해 AI가 시민에게 어떤 의미여야 하는지를 시민과 함께 논의합니다. (11번 AI 카테고리에서도 다룹니다.)

[AI 민주주의 시민질문](https://talks.campaigns.do/goals/aidemocracy){: .btn .btn-outline .fs-3 }

### 16. AI 민주주의 시민실험실

✅ 구현 완료
{: .label .label-green }

시민과 노동자가 AI를 직접 다뤄보며 아이디어를 만들어 보는 자리. "일하는 사람과 일터를 위한 AI 아이디어톤"을 통해 AI가 일터와 일상에 들어올 때 시민이 그것을 어떻게 쓰고 바꿔갈 수 있을지를 직접 실험합니다. 형식이 정해진 본격적 시민의회는 11번 AI 카테고리의 향후 과제로 다룹니다.

### 17. 한국의 대화 (한겨레-빠띠 공동)

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

한겨레와 빠띠가 공동으로 운영하는 사회적 갈등 해소 대화 프로그램. 빠띠의 은하투표·별별대화 방법론을 활용해 가장 다른 의견을 가진 시민을 매칭하고 깊이 있는 1:1 대화를 진행합니다. 대화 전후의 의견 변화를 데이터로 추적합니다.

[한국의 대화](https://talks.campaigns.do/goals/parti-talks){: .btn .btn-outline .fs-3 }

### 18. 서울교육 소통광장

✅ 구현 완료
{: .label .label-green }

서울시교육청의 시민협력플랫폼. 학생·학부모·교직원·시민 누구나 서울교육 정책과 현안에 의견을 나누고 제안할 수 있는 열린 시민참여 플랫폼입니다.

### 19. 지역 시민협력플랫폼

✅ 구현 완료
{: .label .label-green }

지자체·지역 사회와 협력해 운영되는 시민협력플랫폼들. 부산의 "아임인부산"(사회문제 해결 플랫폼), 은평구의 "참여의큰숲"(온라인 정책 플랫폼), 한국YWCA의 "의료공론플랫폼", 경기도의 마을 정책 플랫폼, 그리고 밀양·전주·춘천·완주 등 여러 지역에서 데모스X 모델이 운영되고 있습니다.

[데모스X 사업 모음](https://demosx.org/pages/demosx-works){: .btn .btn-outline .fs-3 }

## 향후 과제
{: .text-delta }

시민 거버넌스의 다음 도약.

### 20. AI 보조 시민 의견 분류·요약 고도화

⬜ 향후 과제
{: .label }

현재 사용 중인 AI 분석 도구를 더 정교하게 발전시켜, 의제 발굴뿐 아니라 시민 간 합의·차이의 지점을 자동으로 식별하고 시각화하는 단계로 확장. 시민이 자신의 의견이 어디에 위치하는지 즉시 확인할 수 있도록.

### 21. 블록체인 기반 시민 의사결정 검증

⬜ 향후 과제
{: .label }

대규모 시민 의사결정의 결과를 블록체인으로 검증·기록해 신뢰성을 확보하는 기능. 실명인증, 거주지 확인, 위변조 방지 등을 결합해 시민이 결정한 정책 결과가 안정적으로 보장되도록.
