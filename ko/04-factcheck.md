# ✅ 팩트체크
{: .no_toc }

허위정보 시대의 시민 팩트체크. 빠띠는 한국 최초의 시민 참여형 크라우드소싱 팩트체크 플랫폼을 만들었고, 시민이 직접 팩트체커가 되어 진실을 함께 만들어가는 커뮤니티를 운영해 왔습니다. 단순한 사후 검증을 넘어 허위정보의 유통경로를 추적하는 선제적 대응까지 발전시켜 가고 있습니다.

## 플랫폼 기능
{: .text-delta }

빠띠에서 시민이 직접 팩트체크를 작성하고 소비할 수 있는 도구.

### 1. 팩트체크 콘텐츠 작성 형식

✅ 구현 완료
{: .label .label-green }

빠띠에 도입된 팩트체크 전용 글쓰기 형식. 작성자는 더 쉽게 팩트체크 형식의 글을 쓸 수 있고, 사실 여부 판정과 근거를 명확하게 구조화해 정리할 수 있습니다.

[빠띠 팩트체크](https://campaigns.do/factcheck){: .btn .btn-outline .fs-3 }

### 2. 팩트체크 소비자 인터페이스

✅ 구현 완료
{: .label .label-green }

독자가 팩트체크 내용을 한눈에 파악할 수 있도록 설계된 표시 형식. 사실/거짓/판정 보류 등의 결과가 시각적으로 즉시 보이고, 근거와 출처가 함께 노출됩니다.

### 3. 팩트체크 검색·아카이브

✅ 구현 완료
{: .label .label-green }

지난 팩트체크 콘텐츠를 검색하고 탐색할 수 있는 아카이브. 시민이 과거에 검증된 사안을 다시 확인할 수 있도록 합니다.

[빠띠 아카이브](https://campaigns.do/discussions?template=fact_check){: .btn .btn-outline .fs-3 }

## 커뮤니티·방법론
{: .text-delta }

시민이 직접 팩트체커로 활동하는 커뮤니티와 그를 위한 교육·운영.

### 4. K.F.C. 시민팩트체커 커뮤니티

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

Korean Fact-Checkers Community. 빠띠가 자체 운영하는 시민 팩트체커 커뮤니티. 시민이 직접 팩트체커로 활동하며 함께 학습하고 검증해 가는 모임. 전문 기관 중심의 팩트체크 모델을 넘어 시민 참여형 팩트체크 모델을 한국에서 정착시킨 사례.

### 5. 시민 팩트체크 교육·훈련

✅ 구현 완료
{: .label .label-green }

시민이 팩트체커로 성장할 수 있도록 빠띠가 운영하는 교육·훈련 프로그램. 정보 검증 방법, 출처 확인 기법, 팩트체크 글쓰기 등을 체계적으로 학습할 수 있습니다.

### 6. 팩트체크넷 (전 사업)

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

2021~2023년 빠띠가 공동이사장으로 참여해 운영한 한국 최초의 크라우드소싱 팩트체크 플랫폼. 언론사·전문가·시민이 함께 팩트체크를 수행하는 협업 모델을 한국에 처음 도입했고, 한국 팩트체크 생태계 형성에 결정적 기여를 했습니다.

## 연결·국제
{: .text-delta }

국내·국제 팩트체크 생태계와의 협력.

### 7. IFCN 글로벌 팩트체크 펀드 빌드 지원

✅ 구현 완료
{: .label .label-green }

2024년 빠띠가 국제팩트체킹네트워크(IFCN, International Fact-Checking Network)의 글로벌 팩트체크 펀드 '빌드 지원' 사업에 선정. 한국 시민 팩트체크 모델이 국제적으로 인정받은 사례.

### 8. 미디어·언론과의 협력 팩트체크

✅ 구현 완료
{: .label .label-green }

언론사·미디어 단체와의 협력을 통한 공동 팩트체크 프로젝트. 시민의 검증 능력과 언론의 취재력이 결합되는 협업 모델.

## 향후 과제
{: .text-delta }

허위정보 시대의 다음 도전.

### 9. 허위조작정보 유통경로 추적·사전 경고

⬜ 향후 과제
{: .label }

허위조작정보가 어떻게 만들어지고, 어떤 경로로 확산되며, 어떤 커뮤니티에서 어떻게 변형되는지를 추적하는 시스템. 단순한 사후 검증을 넘어 허위정보의 확산 경로를 사전에 파악하고 시민에게 경고를 보내는 선제적 대응 모델.

### 10. AI 보조 팩트체크

⬜ 향후 과제
{: .label }

AI가 팩트체커의 검증 작업을 보조하는 도구. 자료 검색, 출처 확인, 유사 사례 추천 등을 AI가 자동화해 시민 팩트체커의 작업 부담을 줄입니다. AI가 판정을 내리는 것이 아니라 시민이 판정하는 과정을 돕는 방향. (11번 AI 카테고리에서도 다룹니다.)

### 11. 팩트체크 콘텐츠 임팩트 추적

⬜ 향후 과제
{: .label }

팩트체크 결과가 실제로 어떤 영향을 미쳤는지 — 검증된 정보가 얼마나 확산됐는지, 원본 허위정보의 확산이 줄었는지 — 를 자동으로 추적하고 시각화하는 기능.
