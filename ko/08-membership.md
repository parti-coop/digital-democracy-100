# 🎖️ 참여 보상과 멤버십
{: .no_toc }

빠띠는 시민이 광장에 한 번 다녀가는 곳이 아니라, 시민이 머무르고 함께 자라는 곳이 되기를 바랍니다. 시민 멤버십은 그래서 빠띠의 중요한 자산입니다. 빠띠즌이라는 정기 후원 멤버 1,133명, 그들이 자율적으로 만든 187개의 모임과 18개의 프로젝트, 그리고 시민의 활동 궤적을 가시화하는 20개 이상의 배지와 시빅 포인트 시스템이 함께 빠띠 광장의 생명을 만들어갑니다.

## 플랫폼 기능
{: .text-delta }

시민이 빠띠의 멤버로서 광장에 머무르고 활동할 수 있게 하는 도구들.

### 1. 시티즌패스

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

빠띠의 디지털 시민 멤버십. 정기 후원 빠띠즌이 되면 시티즌패스를 가질 수 있고, 빠띠가 운영하는 모든 광장에서 연결과 협업, 그리고 성장의 기회를 누릴 수 있습니다. 1,133명의 멤버가 187개의 모임과 18개의 프로젝트를 이미 만들어가고 있습니다.

[빠띠 시티즌패스](https://pass.campaigns.do){: .btn .btn-outline .fs-3 }

### 2. 빠띠즌 후원 멤버십

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

빠띠를 정기적으로 후원하는 시민 — 빠띠즌. 빠띠가 시민 조합원이 소유하고 운영하는 협동조합이라는 점에서, 빠띠즌은 단순한 후원자가 아니라 빠띠 광장의 공동 소유자입니다. 후원이라는 형태로 빠띠의 디지털 시민 광장이 시민의 것이 되는 구조.

[빠띠즌 가입](https://campaigns.do/users/sign_up){: .btn .btn-outline .fs-3 }

### 3. 멤버 자율 모임 시스템

✅ 구현 완료
{: .label .label-green }

시티즌패스 멤버가 자율적으로 만드는 다양한 모임. 빠띠가 정해주는 모임이 아니라 멤버가 직접 발의하고 운영하는 187개의 모임이 다양한 주제와 형태로 진행되고 있습니다.

[빠띠 모임](https://pass.campaigns.do/boards/get-together){: .btn .btn-outline .fs-3 }

### 4. 멤버 협업 프로젝트 인큐베이션

✅ 구현 완료
{: .label .label-green }

멤버가 함께 진행하는 협업 프로젝트를 빠띠가 함께 키우는 인큐베이션 시스템. 18개의 프로젝트가 이미 진행 중이며, 시민의 아이디어가 실제 사회 변화로 이어지는 통로 역할을 합니다.

### 5. 멤버 툴킷·자원 공유

✅ 구현 완료
{: .label .label-green }

멤버가 자기 활동을 발전시킬 수 있도록 빠띠가 제공하는 도구·자원 패키지. 캠페인 운영 도구, 모임 진행 가이드, 디지털 시민 역량 도구 등을 한자리에서 만날 수 있습니다.

[빠띠 툴킷](https://pass.campaigns.do/pages/toolkit){: .btn .btn-outline .fs-3 }

### 6. 멤버 스토리 아카이브

✅ 구현 완료
{: .label .label-green }

멤버들의 이야기를 기록하고 공유하는 아카이브. 빠띠 광장에서 만들어진 시민 스토리가 다른 시민에게 영감과 동기가 되는 선순환 구조.

[멤버 스토리](https://pass.campaigns.do/boards/story){: .btn .btn-outline .fs-3 }

### 7. 활동 배지 시스템

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

시민이 캠페인·후원·기억·데이터·민주주의 활동에 참여할 때 부여되는 배지 시스템. 20개 이상의 배지가 활성화되어 있으며, "10,000번째 기억 지킴이" 같은 순번 배지, 활동량 기준 배지("10건 이상", "100건 이상"), 연도별 후원 배지, 특정 캠페인 참여 배지 등 다양한 형태로 시민의 활동 궤적을 가시화합니다. 받은 배지는 프로필에 표시하거나 SNS에 공유할 수 있어 시민의 디지털 시민성이 자연스럽게 드러나도록 설계되었습니다. 외부 단체(참여연대, 한살림, 국립공원을지키는시민의모임 등)도 자체 배지를 발급할 수 있어 빠띠 광장이 시민 활동의 공통 인정 인프라 역할을 합니다.

[빠띠 배지](https://campaigns.do/badges){: .btn .btn-outline .fs-3 }

### 8. 시빅 포인트

🔧 개발 중
{: .label .label-yellow }
⭐ 빠띠 오리지널
{: .label .label-purple }

시민이 빠띠 광장에서 한 다양한 활동(투표, 토론, 캠페인 참여, 팩트체크, 데이터 기여 등)에 시빅 포인트를 누적하고, 이를 다양한 방식으로 활용할 수 있게 하는 시스템. 단순한 게임화가 아니라 시민의 활동을 가시화하고 인정하는 새로운 시민성 인프라.

## 이벤트·방법론
{: .text-delta }

멤버들이 함께 모이고 자라는 빠띠의 운영 프로그램.

### 9. 빠띠즌 정기 모임

✅ 구현 완료
{: .label .label-green }

빠띠즌들이 정기적으로 만나는 오프라인·온라인 모임. 시민이 단순한 멤버에서 시민 활동가로, 시민 활동가에서 캠페이너로 성장하는 경로를 함께 만들어 갑니다.

### 10. 캠페이너 인생게임

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

캠페인 운영 과정을 게임으로 체험하는 빠띠의 워크숍 방법론. 멤버가 가상의 캠페인 과정을 따라가며 캠페이너의 역할을 직접 경험합니다. (3번 시민 캠페인 카테고리에서 자세히 다룹니다.)

## 향후 과제
{: .text-delta }

시민 멤버십의 다음 진화.

### 11. 시민 멤버십 인터로퍼러빌리티

⬜ 향후 과제
{: .label }

빠띠 멤버십과 다른 협동조합·시민단체·플랫폼의 멤버십이 서로 연결되어, 한 시민이 여러 조직의 멤버이면서도 통합된 시민 경험을 가질 수 있도록 하는 인프라. 빠띠 안과 밖의 시민 멤버십 생태계.

### 12. 시민 토큰 이코노미·DAO 실험

⬜ 향후 과제
{: .label }

시민이 광장에서 한 활동에 대한 보상과 거버넌스를 시민이 직접 결정할 수 있도록 하는 새로운 구조 실험. 시빅 포인트와 배지 시스템이 발전하면 가능해질 영역.
