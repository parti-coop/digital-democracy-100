# 🏗️ 플랫폼 빌더와 조직 인프라
{: .no_toc }

빠띠가 직접 운영하는 광장과, 다른 조직이 자기 광장을 만들 수 있도록 돕는 빌더 도구. 빠띠와 자매 사업 UFOfactory는 자신의 인프라를 닫아두지 않고 수많은 비영리·협동조합·시민단체와 공유해 왔습니다. 그 결과는 빠띠 안과 밖에서 동시에 자라나는 디지털 시민 광장의 생태계입니다.

## 빠띠 자체 운영 인프라
{: .text-delta }

빠띠가 시민에게 직접 제공하는 광장들을 받치는 공통 인프라.

### 1. 통합 사이트 빌더

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

빠띠가 직접 운영하는 4개 사이트 — 캠페인즈, 시민대화, 시민기술, 시티즌패스 — 가 공통 사용자 계정과 통합 운영 인프라 위에서 작동합니다. 한 시민이 한 번 가입하면 빠띠의 모든 광장을 이용할 수 있고, 빠띠는 광장 간 시너지를 발휘할 수 있습니다. (이 외에 데모스X와 타운홀은 각각 별도 시스템으로 운영됩니다.)

[빠띠 캠페인즈](https://campaigns.do){: .btn .btn-outline .fs-3 }

### 2. 회원·계정 관리 시스템

✅ 구현 완료
{: .label .label-green }

회원 가입, 정보 관리, 권한 설정, 그룹·단체 소속 관리 등을 지원하는 회원 시스템. 개인 회원과 단체 회원, 일반 회원과 운영진을 구분해 관리할 수 있습니다.

### 3. 후원·기부 통합 시스템

✅ 구현 완료
{: .label .label-green }

캠페인 후원, 단체 후원, 정기 후원, 일회성 기부를 한 플랫폼에서 처리할 수 있는 시스템. 시민이 캠페인에 참여하는 동시에 자연스럽게 후원으로 이어질 수 있도록 설계되어 있습니다.

### 4. 이메일·뉴스레터 발송

✅ 구현 완료
{: .label .label-green }

캠페인 참여자에게 진행 상황을 자동으로 알리고, 단체가 회원에게 뉴스레터를 발송할 수 있는 시스템. UFOfactory 시기에 분사시킨 한국의 대표적 비영리 이메일 플랫폼 스티비의 정신을 잇고 있습니다.

### 5. 데이터 다운로드·통계

✅ 구현 완료
{: .label .label-green }

투표 결과, 토론 데이터, 회원 명단 등을 CSV·Excel·PDF 형태로 다운로드할 수 있는 기능. 운영자가 자기 광장의 데이터를 자유롭게 분석·활용할 수 있도록 합니다.

### 6. 권한 관리 시스템

✅ 구현 완료
{: .label .label-green }

단체·그룹·오거나이저·일반 회원 등 다양한 역할에 맞춰 권한을 세분화해 관리할 수 있는 시스템. 한 플랫폼 안에 여러 단체와 모임이 자기 자율성을 가지고 공존할 수 있습니다.

## 다른 조직을 위한 빌더 도구
{: .text-delta }

빠띠와 UFOfactory가 자체 인프라를 오픈소스·플랫폼 형태로 공개해, 다른 조직도 자기 광장을 만들 수 있게 한 도구들.

### 7. UFOfactory — 공익 기술 개발

✅ 구현 완료
{: .label .label-green }
⭐ UFOfactory 사업
{: .label .label-blue }

빠띠의 자매 사업 UFOfactory는 공익 기술·솔루션·서비스를 직접 개발하는 곳입니다. 2013년부터 비영리·협동조합·시민단체가 필요로 하는 디지털 도구를 연구·개발하고, 검증된 솔루션을 분사·이전하는 인큐베이션 모델을 운영해 왔습니다. 적정기술 솔루션 믹스온도 UFOfactory가 개발해 운영하고 있습니다. 빠띠가 민주주의 영역의 시민 광장을 맡는다면, UFOfactory는 공익 기술 개발을 맡아 — 두 자매 사업이 공익 기술 생태계를 함께 키웁니다.

### 8. 믹스온

✅ 구현 완료
{: .label .label-green }
⭐ UFOfactory 사업
{: .label .label-blue }

비영리·협동조합·커뮤니티 조직이 자기 광장을 직접 만들 수 있도록 빠띠의 자매 사업 UFOfactory가 운영하는 적정기술 솔루션. 캠페인 사이트, 커뮤니티 플랫폼, 데이터 수집 도구 등을 기획부터 운영까지 통합 제공합니다. 동네방네 공익위키(경기도공익활동지원센터), 디지털마중물지원사업(서울사회복지공동모금회), 남성과함께하는페미니즘, 도미니 마을공론장, 21%클럽 등이 믹스온 위에서 작동하고 있습니다.

[믹스온](https://mixon.io){: .btn .btn-outline .fs-3 }

### 9. 데모스X 오픈소스 플랫폼

✅ 구현 완료
{: .label .label-green }
⭐ 빠띠 오리지널
{: .label .label-purple }

빠띠가 자체 개발한 시민협력플랫폼 데모스X가 오픈소스로 공개되어 있어, 정부·지자체·기관 누구나 자기 시민협력플랫폼을 만들 수 있습니다. 200여 회의 공론장 운영 경험과 운영 가이드까지 함께 공개되어 있어 처음부터 만들 필요 없이 검증된 모델을 가져다 발전시킬 수 있습니다. (5번 거버넌스 카테고리에서 더 자세히 다룹니다.)

[데모스X](https://demosx.org){: .btn .btn-outline .fs-3 }

## 이벤트·방법론
{: .text-delta }

빠띠와 UFOfactory가 다른 조직의 디지털 인프라를 함께 만들어온 방식.

### 10. 비영리 디지털 전환 컨설팅

✅ 구현 완료
{: .label .label-green }

비영리·협동조합·시민단체의 디지털 전환을 함께 설계하고 운영하는 컨설팅. 현장에 필요한 기술을 기획부터 운영까지 통합해 제공합니다.

### 11. 1,200개 이상 비영리 디지털 인프라 구축 경험

✅ 구현 완료
{: .label .label-green }
⭐ UFOfactory 사업
{: .label .label-blue }

UFOfactory가 2013년부터 누적해온 1,200개 이상의 비영리·협동조합·시민단체와의 디지털 인프라 구축 경험(2017년 기준). 한국 비영리 영역에서 가장 폭넓은 디지털 전환 파트너십 자산. 이 경험이 믹스온과 빠띠 통합 인프라의 토대가 되었습니다.

## 향후 과제
{: .text-delta }

빠띠 인프라의 다음 도약.

### 12. 통합 API 인프라

⬜ 향후 과제
{: .label }

빠띠의 모든 광장과 도구가 외부 시스템과 자유롭게 연결될 수 있는 공개 API 인프라. 다른 조직이 자기 시스템에서 빠띠의 시민 데이터·캠페인·투표 기능을 활용할 수 있도록.

### 13. 시민 멤버십 통합 시스템

⬜ 향후 과제
{: .label }

빠띠 안과 밖, 그리고 다른 조직의 멤버십을 통합 관리할 수 있는 시스템. 한 시민이 여러 조직의 회원이면서도 통합된 시민 경험을 가질 수 있도록.
